# Tokito Music 🎵

Free music streaming app for Android with a Spotify-style dark UI —
320kbps quality, unlimited skips, playlists, liked songs, background playback,
and Firebase cloud sync. No ads, no subscription.

**⬇️ Download the APK:** https://t4tokito-store.netlify.app/apps/tokito-music
**🏬 More free apps:** https://t4tokito-store.netlify.app/ (t4tokito Store)

## Stack

Expo SDK 57 · React Native · Expo Router · expo-audio · Firebase Auth/Firestore

## Development

```bash
npm install
npx expo start
```
